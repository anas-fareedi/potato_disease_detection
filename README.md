# potato disease detection

This project is an end-to-end deep learning application designed to detect and classify diseases in potato plants from leaf images. By leveraging a Convolutional Neural Network (CNN), the system can identify common diseases like Early Blight and Late Blight, as well as distinguish healthy leaves, providing a valuable tool for modern agriculture.​

The application is served via a FastAPI backend, providing a RESTful API for predictions, and includes a simple web interface for user interaction.

## Features

Disease Classification: Accurately classifies potato leaf images into three categories: Early Blight, Late Blight, and Healthy.​

Deep Learning Model: Built with a Convolutional Neural Network (CNN) using TensorFlow and Keras, trained for high accuracy on image data.​

REST API: A robust backend powered by FastAPI exposes the model's prediction capabilities through an API endpoint.

Interactive Web Interface: A clean and simple frontend built with HTML, CSS, and JavaScript allows users to easily upload an image and view the prediction results.

Automated API Docs: Interactive API documentation is automatically generated by FastAPI via Swagger UI and ReDoc.

Backend: Python, FastAPI

Deep Learning: TensorFlow, Keras

Image Processing: Pillow

Web Server: Uvicorn

## How It Works

The application follows a simple, effective workflow:

A user uploads an image of a potato leaf through the web interface.

The frontend sends the image file to a specific endpoint on the FastAPI backend.

The backend pre-processes the image to match the model's input requirements (e.g., resizing to 256x256 pixels, normalization).

The processed image is passed to the loaded CNN model for inference.

The model returns a prediction (the disease class and confidence score).

The FastAPI backend sends this prediction back to the frontend, which displays the result to the user.

## Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Python 3.9+
Git

## Installation & Setup
### Clone the repository:
```
bash
git clone https://github.com/anas-fareedi/potato_disease_detection.git
cd potato_disease_detection
```

### Create and activate a virtual environment:
```
bash
# For Windows
python -m venv venv
.\venv\Scripts\activate
```

### Install the required dependencies:
```
bash
pip install -r requirements.txt
```
### Download the pre-trained model:
You will need the trained model file (.h5 or a saved_model directory). Place it in the models directory within the project.

### Run the application:

Start the development server with Uvicorn.
```
bash
uvicorn main:app --reload
The application will be running at http://127.0.0.1:8000.
```

### API Documentation

Once the server is running, you can access the interactive API documentation at:

Swagger UI: http://127.0.0.1:8000/docs

ReDoc: http://127.0.0.1:8000/redoc
